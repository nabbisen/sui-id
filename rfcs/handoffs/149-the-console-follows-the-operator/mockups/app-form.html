The app form (RFC 149 §3 and §4)

The labels and lines in grey are layer 1: always shown, because without them a reader could make a mistake. The ? buttons are layer 2: they open in place on a click, a tap or the keyboard, and close again. There are no hover tooltips. It all works with JavaScript off: Add another submits, and the page returns with one more row.

? What is a redirect URI
After sign-in, sui-id sends the user back only to an address listed here, exactly as written. Add one for each place your app receives the sign-in, for example the live site and a test site. Learn more

Redirect URI 2 must start with https:// (http:// is allowed only for localhost, 127.0.0.1 or ::1, while testing).
