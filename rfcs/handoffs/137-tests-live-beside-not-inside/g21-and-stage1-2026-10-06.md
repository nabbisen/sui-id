# RFC 137 — G21, then stage 1

**RFC status: Accepted** 2026-10-06, scoped to `crates/*/src/`.
`crates/*/tests/` is out of scope and **not** measured; claim nothing about it.

**Dispatched: the gate, then stage 1.** Stages 2–4 are not dispatched.

## Step 1 — G21, before any file moves

Fails when a file under `crates/*/src/` declares a test module **inline** — a
`#[cfg(test)]` module with a body — rather than `mod …;` pointing at a sibling
file.

**Match the module, not the name.** The count went 70 → 77 when I widened my own
grep from `mod tests` to any `mod …tests`; modules are named
`redirect_uri_matches_tests` and similar. **Detect the construct.**

**The 77 are a shrink-only exemption list**, built from the real tree, each
migration deleting one line. Carry G20's discipline exactly: **an exempted file
that no longer needs the exemption is an error**, so a stale entry fails rather
than lingering.

Register in all three places in `contracts/gate-inputs.toml` as G19 and G20
were, and add the lane table to RFC 137 — A3.4 condition 7 compares it
byte-for-byte, and my first attempt at that for RFC 135 used the wrong columns.

**State the proxy limit in the docstring**, as `check-rfc-integrity.py` and G19
do: a textual scan proves the construct is absent as written, not impossible.

## Step 2 — stage 1: `sui-id-web` (1), `sui-id-shared` (4), `sui-id-i18n` (5)

Ten files, three small crates, to prove the method before the large ones.

For each: `src/foo.rs`'s `#[cfg(test)] mod tests { … }` becomes
`#[cfg(test)] mod tests;` plus `src/foo/tests.rs`. The child keeps `super::`
access to private items, which is why this works. Rust 2018+ lets `foo.rs` and
`foo/` coexist with no `mod.rs`.

**Pure relocation.** No test renamed, added, deleted or rewritten; no
implementation line changed beyond the `mod` declaration.

## The proof, and nothing else counts

**A move that silently drops a test module compiles and passes** — `cargo test`
reports fewer tests and nothing fails.

**State the exact test count for each of the three crates before and after.
They must be equal.** "The suite passes" is not evidence of anything here.

## Return

Per-hunk SHA-256 against a stated baseline, the per-crate before/after counts,
G21's output showing the exemption list down by ten, and the full local gate set
— **including A3.2, G19 and G20**.
