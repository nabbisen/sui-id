## 4. What to report

For each section, whether it can be built as written. Concretely:

- **Under-specified** — a command whose class is unstated; an evidence
  requirement with no producible artifact; a validation rule whose order or
  precedence is ambiguous; an error contract that does not say what the caller
  observes.
- **Contradictory** — two sections that cannot both hold. You found two of these
  last pass, both real.
- **Impossible as written** — a prerequisite unsatisfiable in the stated order, a
  test that cannot pass by the route it names. A1 was exactly this shape:
  the RFC required `ATTACH` to be "rejected as non-read-only", which measurement
  showed cannot happen.
- **Missing artifacts** — files, policy tables, or binaries the RFC depends on
  that do not exist and are not scheduled. You found the `xtask` /
  `ci/write-authority.toml` gap this way.

**Where a question is decidable by running something, run it.** That is what made
A1 and A2 conclusive rather than arguable.
